# Typage Labs

**Making invalid states unrepresentable.**

Typage Labs develops open-source libraries that bring stronger
compile-time guarantees to existing APIs.

Our goal is simple: catch more programming errors at compile time,
without sacrificing performance, interoperability, or developer experience.

## Libraries

- **TypedCoreData** — Type-safe identities and operations for Core Data.
- **TypedSymbols** — Type-safe access to Apple's SF Symbols.

## Principles

- Compile-time safety over runtime checks.
- Minimal abstractions with meaningful guarantees.
- Native interoperability.
- Thorough testing, including negative compilation tests.
- Open-source software built for real-world use.
